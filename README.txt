GREENROOTS — STUDENT PROJECT WEBSITE

CONTENTS
- index.html: website structure and project content
- style.css: responsive layout, colors, typography and styling
- script.js: mobile navigation and interactive distance detector demo
- assets/: photographs and illustrations extracted from the supplied project PDF

HOW TO OPEN
1. Extract the ZIP file to a folder.
2. Open the extracted folder.
3. Double-click index.html. It opens in a modern web browser.

EDITING
- Change text in index.html.
- Change colors and layout in style.css (CSS variables are near the top).
- Change the demo interaction in script.js.
- Keep the assets folder beside index.html so the photographs load correctly.

NOTES
- The distance slider is a browser-based simulation, not a connection to physical Arduino hardware.
- Project photographs are from the PDF supplied in this conversation.
- The project report's Arduino mini-project content and horticulture community-service content are both represented.
